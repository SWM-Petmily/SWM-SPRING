# 펫밀리(Petmily) - 신뢰성있는 반려동물 분양 서비스
- 기간: 2023.05 - 2023.11
- 인원: Spring 2명, iOS 1명

# 프로젝트 목표
반려동물을 입양/분양하는 기존 서비스의 문제점을 개선하고 신종 펫숍으로 인한 피해 사례를 줄이고 신뢰성있게 반려동물을 분양/입양 할 수 있는 서비스를 지원
- 신종 펫숍 유의사항 가이드를 제공
- 반려동물 입양/분양에 필요한 정보들을 필수적으로 작성
- 동물등록번호, 건강검진정보, 예방접종 인증을 통해 신뢰성을 높힘
- 계약서 작성을 통해 입양/분양 이후 발생하는 문제해결
